# Original photos

`scripts/build_photos.py` downloads each chapter's original photo here, named
by chapter (`03-canal.jpg`), from the URL in `production/photos.toml`. The
photos belong to the [New Bremen Historic Association](https://newbremenhistory.org/en/content/category/25-photo-galleries),
so they are kept out of git, and the site must not be published with them
until the association gives permission. Credits and captions are in
`production/photos.toml`.
